# Cardback Radar

Een kleine webapp met de dagelijkse stand van zaken in de actiefigurenscene,
gemaakt voor de Instagram-pagina TheDadWhoKeptHisToys.

De inhoud staat in `data.json` en wordt elke ochtend automatisch bijgewerkt.
`index.html` toont die inhoud; de app is te installeren op een telefoon en
werkt offline met de laatst opgehaalde stand.
